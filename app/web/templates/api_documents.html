JSON Responses
Method URL Endpoint Description & Features Actions
GET /api/health Service health check returning status, version, and NAS availability flag. Open
GET /api/dashboard Summary statistics (total, new, existing, duplicates, removed), scheduler status, and latest events. Open
GET /api/files List monitored files with query filters: q (search), status (NEW/EXISTING/REMOVED), limit, offset. Open
GET /api/files/new Returns only files discovered in the current or most recent scan lifecycle. Open
GET /api/files/previous Returns previously monitored files that continue to exist on the storage volume. Open
GET /api/files/duplicates Detailed duplicate clusters grouping copies by SHA-256 and requisition report code with first vs latest occurrence. Open
GET /api/files/removed Historical registry of removed / deleted files with original metadata preserved. Open
GET /api/files/{id} Single file metadata details and complete event history timeline. Example #1
GET /api/events Activity ledger events stream (ADDED, SEEN, MODIFIED, REMOVED, RESTORED, DUPLICATE_DETECTED). Open
GET /api/scans Historical scan runs log with start/completion times, durations, and counts. Open
POST /api/scan Trigger an immediate on-demand filesystem scan. Prevents overlapping runs with mutual exclusion lock.
GET /api/export/files Export file registry as CSV download (?format=csv) or JSON (?format=json). CSV
GET /api/export/duplicates Export duplicate groups registry as CSV download (?format=csv) or JSON (?format=json). CSV
